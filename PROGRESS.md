# PROGRESS — Журнал реализации ТЗ проекта «ИРСИ»

> Технический журнал прогресса по реализации ТЗ (сервис онлайн-записи для
> мастеров-одиночек, домен irsi-app.ru). Дописывается по мере выполнения волн.
> Единственный источник правды по объёму работ — «ТЗ одиночки.docx».

> **Легенда статусов:** ✅ = задеплоено на прод · 🧪 = закоммичено+запушено, ждёт деплоя · ⏳ = в бэклоге

> **Стек:** Laravel (PHP 8.4) + React/Inertia/TSX + PostgreSQL + Redis + Laravel Reverb.
> Боты Telegram + MAX. Репозиторий: github.com/nickup8/vovremya · Прод: /var/www/irsi-app
